# Access
Before starting anything, you need to follow 3 steps from [*Getting Started with C++*](https://docs.discord.com/developers/discord-social-sdk/getting-started/using-c++#step-1-create-a-discord-developer-team):  

- Step 1: Create a Discord Developer Team.  
- Step 2: Create a Discord Application.  
- Step 3: Enable Discord Social SDK for Your App.  

Otherwise Discord will not let use their SDK.
