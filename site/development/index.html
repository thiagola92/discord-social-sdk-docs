GDExtension

This GDExtension is just a wrapper around Discord Social SDK, which means that you call the GDExtension method and it calls the SDK method. 

flowchart LR
    gdscript[GDScript]
    gdextension[GDExtension]
    sdk[SDK]

    gdscript --"Discord.enum_to_string()"--> gdextension
    gdextension --discordpp::EnumToString()--> sdk

    sdk --"std::string"--> gdextension
    gdextension --"String"--> gdscript

Basically, this GDExtension job is convert between Godot variables and C++ variables.

For example, when you pass a String to a GDExtension method, it will convert to std::string before passing to the SDK method. And the opposite convertion needs to happen when returning from SDK.

Project Tree

.
├── demo/

├── include/
│   └── Discord headers
├── lib/
│   └── Discord libs
├── scripts/
│   └── Python scripts
└── src/
    └── GDExtension source codes and headers

All the important code is written in Python (inside scripts) and this code is responsible for generating the GDExtension code (inside src). So let me be very clear...

No code should be manually added to src directory!
